- [x] Vision §3.10 data posture honored in the spine (offline/local-first; no live calls).

  provenance intact.

**Status 2026-08-09:** complete — contracts, graph wiring (time-bounded `LOCATED_AT`,

Labels: `wayfinder:task`. Blocked by: Slice 1.

## Slice 4 — Mind palace

Labels: `wayfinder:task`. Blocked by: Slice 3.

### Checklist

- [x] Generated navigable space: chambers = related-node clusters, paths = graph edges.
- [x] Memory-palace conventions: spatial anchors, chunking; palace walks = curated scene
  sequences with chamber anchors.
- [x] Curation surface: pin / exclude / rename / reorder chambers; raw graph untouched
  (persisted per profile in the SQLite profile store).
- [x] Profile-aware shaping (bootstrapping vs migration vocabulary).
- [x] Guided recall as a viewing mode over the generated palace.
- [x] Real tests: clustering, walk assembly, curation semantics.

### Acceptance

- A palace is generated from a real graph, curated in-app, and walked as a scene sequence.
