# Episode 1-2 Archetypal Resonance Ledger

Companion ledger for `episode-1-2-archetypal-resonance.mmd`.

This is not a timeline. It maps imaginal genealogy, archetypal resonance, inversion, and historical incarnation across Episode 1 and Episode 2. Episode 1 defines the image-system. Episode 2 historicizes it.

## Core Principle

The root distinction is:

| Layer | Meaning | Graph Use |
|---|---|---|
| Archetype-as-such | Irrepresentable generative pattern; the strange attractor or empty hub. | Usually one high-level `Archetype` node. |
| Archetypal image | A specific imaginal orbit of that pattern: Devil, Christ, Prometheus, Black Sun, Lamb, Eagle, etc. | `Image` or `ArchetypeImage` node. |
| Resonance | A harmonic relation between images, not necessarily direct causality. | `RESONATES_WITH`, `ECHOES`, `INVERTS`, `COMPLEMENTS`. |
| Incarnation | A historical or institutional form in which an image becomes socially operative. | `INCARNATES_AS` from image/vector to `Event` or `Institution`. |

The map should stay spectral. A node can carry multiple resonances. The Medici are dominantly Bull/Ox, but Eagle/Owl and Lion/Jaguar are also present. Epstein is dominantly Lion/Jaguar, but Lamb/Sheep, Eagle/Owl, Dog/Wolf, Frankenstein, Record Keeper, Chemist, and Power/Magic all sound.

## Relationship Types For Neo4j

Use a small, readable relationship vocabulary. Avoid turning every poetic nuance into a one-off edge label.

| Relationship | Meaning |
|---|---|
| `GENERATES_IMAGE` | Archetype-as-such produces an image or image family. |
| `RESONATES_WITH` | Harmonic similarity without hierarchy or causality. |
| `INVERTS` | Same structure, opposite direction of flow. |
| `COMPLEMENTS` | One image completes or reveals the missing half of another. |
| `SHADOWS` | Repressed or hidden counterpart. |
| `RESTORES` | Redemptive return of an inverted image. |
| `SACRIFICES` | Gives/takes a named object of sacrifice. |
| `FEEDS` | Nourishes or sustains without extraction. |
| `DEVOURS` | Consumes the many into the one. |
| `OCCULTS` | Hides, privatizes, or drives underground. |
| `FABRICATES` | Builds substitute identity or appearance. |
| `INCARNATES_AS` | Archetypal image becomes historically operative. |
| `OPERATES_AS` | A historical form works through a conceptual operation. |
| `DOMINANT_FREQUENCY` | Main resonance for a historical block. |
| `SECONDARY_FREQUENCY` | Supporting resonance for a historical block. |
